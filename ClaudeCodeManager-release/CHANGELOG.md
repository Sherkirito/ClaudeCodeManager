# Changelog

## v2.0-preview.16 — 2026-08-13

### 新增

- **Agent team 收纳** — 新增“团队”导航页：团队列表与团队详情（lead、成员角色、任务描述、颜色标识与关联置信度），团队成员会话点击直达详情
- **队友会话筛选** — 跨项目会话页类型筛选新增“队友会话”；队友行显示角色与所属团队标签，无 lead 时明确标注“lead 会话未收录”
- **teammate 消息展示** — 会话详情解析 `<teammate-message>` 信封，按发送者与摘要折叠展示，兼容多信封、缺省属性与 JSON payload
- **团队统计** — 团队级会话/消息/Token/最近活跃聚合；工作台主会话卡片同步显示团队数
- **回收站连带清理** — 队友会话移入回收站时一并带走成员 .meta.json 元数据，父会话与其他会话不受影响

### 稳定性

- **lead 三级证据关联** — 成员 agentId、物理目录、meta teamName 级联关联并双向唯一防误配；lead 会话轮换后旧 lead 不再被误标为队友
- **索引全量回填** — 索引 schema 升级至 v5，首次启动自动重建以补齐团队字段
- **隐私** — 团队索引不持久化成员 cwd（展示值取自已索引的 lead 会话）；颜色渲染白名单校验；搜索结果显示会话类型与团队标签
- **兼容** — 会话列表 API 新增 `kind=teammate` 与 `teammate_total`，既有筛选与统计口径不变；64 个测试全部通过

## v2.0-preview.15 — 2026-08-13

### 新增

- **自动会话可见且可管理** — 跨项目会话页新增会话类型筛选（全部 / 主会话 / 自动会话），默认展示全部会话，后台 Job、SDK 自动会话与 Subagent 不再只藏在折叠区域里
- **项目详情自动会话区块** — 主会话与自动会话分区展示；有父会话的自动会话显示父子关系并可跳转母会话，无父会话的明确标注“未关联父会话”，同一会话不会重复出现
- **Subagent 消息按需读取** — Subagent 日志默认不写入索引；详情页现按需读取原始 JSONL，分页展示消息并重算全量 Token 统计，原始文件不被修改；原始日志缺失时明确提示“该自动会话消息尚未建立索引”
- **自动会话管理能力** — 自动会话支持查看详情、搜索、移入回收站、单个与批量回收站；界面保留“仅查看”标注，不提供不安全的“恢复”入口

### 稳定性

- **嵌套日志安全解析** — 回收站与删除操作通过索引解析 Subagent 嵌套文件路径，沿用 realpath 路径包含校验，绝不误删父会话或其他会话
- **统计口径保持清晰** — 主会话计数不含自动会话；项目列表与详情新增“全部会话”统计并明确标注；搜索结果显示会话类型与父会话标签
- **向后兼容** — 会话列表 API 新增 `kind` 筛选参数，缺省行为与旧版一致；现有主会话列表、搜索与回收站测试全部通过

## v2.0-preview.14 — 2026-08-11

### 新增

- **阅读优先的会话详情** — 用户消息与助手正文直接展示，Agent 工具调用和执行结果不再挤占主要阅读区域

- **CC Switch 精确计费** — 工作台优先只读 `~/.cc-switch/cc-switch.db`，仅统计 `proxy_request_logs.app_type = 'claude'` 的 Claude Code 记录，明确排除 Codex 与 Claude Desktop

## v2.0-preview.7 — 2026-07-31

### 新增

- **独立桌面窗口** — 使用 pywebview + WebView2 承载现有 HTML/CSS/JS，默认不再打开浏览器标签页
- **桌面生命周期** — 关闭窗口同步结束本地服务，重复启动会恢复并唤醒已有窗口
- **浏览器回退模式** — `python app.py --browser` 可继续使用原浏览器调试方式

### 性能

- **并发 HTTP 服务** — 改用多线程 loopback 服务，索引、AI 请求和页面资源不再互相阻塞
- **静态资源缓存** — 增加进程内资源缓存、ETag、长缓存版本化资源和 HTTP/1.1 Content-Length
- **索引查询降载** — 扫描前一次性读取 JSONL 文件签名，移除逐文件 SQLite 查询
- **无变化快速路径** — 未检测到 JSONL 增删改时跳过会话关系、逻辑项目和统计全量重算
- **数据库初始化缓存** — 每个 SQLite 文件只执行一次建表和迁移检查，并增加并发 busy timeout
- **索引一致性** — 无变化快速路径仍会清理无会话的历史项目行，避免 Dashboard 项目数残留
- **Windows 包体瘦身** — 排除不使用的跨平台渲染器和 NumPy/Pillow 等可选依赖，运行时由约 101.5 MB 降至约 35 MB

### 工程

- **冻结运行时诊断** — windowed EXE 安全处理无 stdout/stderr 场景，未捕获异常写入 `data/runtime-error.log`
- **Conda DLL 收集** — 显式打包 expat、lzma、bz2、decimal 依赖，避免 pywebview/pythonnet 启动钩子加载失败
